01 / About

CysraOS started from a simple frustration: most desktops are either heavy or ugly, and rarely both fast and good looking. We wanted something you can install, open and actually enjoy.

So the base system stays lean, and the Plasma desktop gets the polish: themes, icons and layouts that look good from the first boot, and that you can still change however you like.

04 / Wiki

Install it. Fix it.

Installing CysraOS 1.0

Boot from your CysraOS USB drive and follow these steps.

  1. In the GRUB menu, select the first option and wait 1-2 minutes for the live session to load.
  2. If Calamares shows an error, close Calamares and open the Install CysraOS 1.0 file on the desktop instead.
  3. Wait 1-2 minutes until the Welcome screen appears.
  4. Set your keyboard layout and language, then choose your disk partitions and continue with the installer.

Troubleshooting

Common installer issues and how to solve them.

  1. Calamares fails to start or shows an error. Close it, then double-click Install CysraOS 1.0 on the desktop.
  2. The Welcome screen takes a while. This is normal. Wait 1-2 minutes before doing anything else.
  3. Black screen after GRUB. Reboot, pick the first GRUB entry again and give it time to load.

Before You Begin

A little preparation makes installation smoother.

  1. Download the ISO and verify its SHA256 checksum.
  2. Write the ISO to a USB drive with a tool of your choice.
  3. Back up important data. Partitioning can erase existing files.
  4. Boot from the USB drive using your firmware's boot menu.
Check the System Requirements section to make sure your hardware is supported.
